# R13 look lane spec: chapter board themes + sellable cosmetics

Game: Long Cat Out! (ES modules + Canvas2D + DOM UI, EN + TR). Keep the change small. Reuse existing code. No new options
beyond this spec. No backend, no accounts, no real money (premium items go through the existing IAP stub `src/kit/iap.js`).

## HARD PERF RULES (phones lag from compositing)
- Every board-theme effect is drawn ONCE into the baked perf underlay (`src/game/perf.js` rebuild ->
  `src/game/render-depth.js` buildFar / buildNear -> `game.drawBoard7` / `shape.drawShapedRug` / `game.drawPlank`).
  Nothing new per frame: no new shadowBlur, filters, gradients or composite ops in per-frame paths.
- Cat skins must go through the existing still-cat sprite cache (`perf.js` ~line 396, key `${st.pal.name}|...`).
  A skinned palette must have its own `name` so the cache key changes.
- No infinite CSS animations on big elements. No page scroll at 375x667. Respect `prefers-reduced-motion`.
- Colour is gameplay (a cat goes into the carrier of its colour). A cat skin must KEEP each cat's base hue readable
  and must keep the fur pattern badge (`drawPatBadge`) unchanged. Never recolour carriers by skin.

## 1. Per-chapter board themes (free, automatic)
Chapters are 10 levels (`data/hub.js` CHAPTER_LEN). The map ground per chapter is `mapTheme(c)` in
`src/ui/look-world.js` (garden, autumn, snow, lantern, beach, bakery, cycling by ORDER). Import `mapTheme` from there
(it only imports `assetUrl`), do not copy ORDER.

Add a LOOKS table in `data/shop.js` (one entry per theme):
`{ room: '<r7 art name>', rug: '#hex', stitch: '#hex', tile: 'rgba(...)' | null, wash: 'rgba(...)' | null, plank: '#hex' | null }`
- garden:  room `bg_play_room`, rug `#C24312` (today's rust), stitch `#FBE3BE`, tile null, wash null, plank null
  (chapter 1 must look exactly like today).
- autumn:  room `brd_autumn`, rug deep pumpkin/brick, stitch cream, light amber tile tint, plank null.
- snow:    room `brd_snow`, rug winter blue, stitch white, cool tile tint, plank light birch.
- lantern: room `brd_lantern`, rug plum/burgundy, stitch gold, warm tile tint, plank dark walnut.
- beach:   room `brd_beach`, rug teal/turquoise, stitch sand-white, sandy tile tint, plank driftwood.
- bakery:  room `bg_bakery`, rug strawberry-cream/rose, stitch white, warm cream tile, plank honey.
- galaxy (premium only): room `brd_galaxy`, rug deep indigo, stitch gold, faint lilac tile tint.
- candy (premium only):  room `brd_candy`, rug bubblegum pink, stitch white, faint pink tile tint.
- night (existing `room_night`): navy rug, gold stitch. blossom (existing `room_blossom`): rose rug, white stitch.
Pick tasteful colours; tiles must stay light (cats must read on them).

Art (already generated by the lead into `public/assets/r7/`): `brd_autumn.webp`, `brd_snow.webp`, `brd_lantern.webp`,
`brd_beach.webp`, `brd_galaxy.webp`, `brd_candy.webp` (1024x1536, same layout as `bg_bakery.webp`).
If a file is missing at runtime, fall back to `bg_play_room` + the look's wash (never crash, never a blank room).
Load room images the way `shop-look.js roomImage()` does (lazy `new Image()` + cache, null until loaded) or add them to
the asset preload list in `src/game/assets.js` ONLY if that list loads lazily; do not make the first load heavier.

Which look the board uses (one function, e.g. `lookOf(game)` in `src/game/shop-look.js`):
1. The equipped 'room' cosmetic (`save.data.shop.eq.room`). The free default `room_sunny` now means
   "Chapter look" (EN) / "Bölüm teması" (TR): the look of the current level's chapter. Keep the id `room_sunny`
   so old saves follow chapters automatically.
2. Any other equipped room item uses its own look + its own room art (every room item gets a `look` key into LOOKS).
3. The level: set `game.lv` per level in `src/ui/content.js levelStart(n, special, board)` (next to `game.theme`).
   Special levels (daily, show, friend) and the home demo use the player's chapter (`save.data.level`).
4. Content packs past L60 (`src/game/content.js room()`, `game.theme`) keep their pack room art, as today, when the
   chapter look is equipped; the rug/stitch/tile/plank still follow the chapter look.
`game.roomArt()` (game.js ~1488) must return the chosen room `{ img, wash, key }`; the key must include the look id so
`perf.js` (sig ~line 237) re-bakes when the look changes. `game.drawBg` non-perf path should use the same choice.

Drawing (baked only):
- `game.drawBoard7`: after the `table_top` 9-slice, recolour the rug to `look.rug` with a clipped
  `globalCompositeOperation = 'color'` (or 'hue') fill over the rug rect, then restore 'source-over'. Skip when the
  look is garden (rug `#C24312`) so chapter 1 is pixel-identical. Stitches in table_top art get recoloured too, that is
  OK; if they get lost, draw no extra stitches (keep it simple).
- `shape.drawShapedRug`: replace the hard-coded `#C24312` felt and `#FBE3BE` stitches with `look.rug` / `look.stitch`
  (pass the look via `g`, e.g. `g.look`).
- Tiles: if `look.tile`, one fill over the tile area (`multiply` or plain low alpha) after the tiles, before the light
  whisper. Same for shaped boards (floor cells only: reuse the clip path already there).
- `game.drawPlank`: if `look.plank`, one clipped 'color' fill over the plank after drawing it.
- buildFar: `art.wash` is already supported.
